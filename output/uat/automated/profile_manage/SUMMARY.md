# ผลทดสอบเปลี่ยนภาพโปรไฟล์

สถานะ: ผ่านกรณีเปลี่ยนภาพสำเร็จและคงอยู่หลังเปิดหน้าใหม่ (บางส่วนของ UAT-04-004)

- บัญชีหลักเดิม ใช้ session เดิม ไม่มีการออกจากระบบหรือขอ OTP เพิ่ม
- เปิดตัวเลือกภาพจริงในโทรศัพท์ แท็บรูปภาพมีภาพล่าสุดแถวแรกซ้าย ระบุถ่ายเมื่อ 15 ตุลาคม 2026 เวลา 20:04; ภาพถัดไประบุ 10 กันยายน 2026
- เลือกภาพล่าสุดหนึ่งภาพ แล้วกดเสร็จสิ้นใน native picker ไม่มีการอัปโหลดไฟล์จำลองหรือเลือกภาพอื่นแทน
- API บันทึก avatarUrl ใหม่ต่างจากก่อนทดสอบ
- Image.network บน Profile ใช้ URL ใหม่และโหลด/ถอดรหัสภาพได้จริง ตรวจเพิ่มด้วยภาพหลักฐาน
- ชื่อและ UID คงเดิม ข้อมูลรูปใน session อัปเดต
- กลับ Home แล้วเปิด Profile ใหม่ รูปเดิมที่เพิ่งเลือกยังแสดงและโหลดได้จริง
- คงรูปใหม่ไว้ตามคำขอ ไม่คืนเป็นรูปเก่า

ไม่ได้ทดสอบกรณีไฟล์ผิดชนิด เกินขนาด ยกเลิกเลือกภาพ หรือเน็ตขัดข้องในรอบนี้ จึงไม่ถือว่าครบทุกเงื่อนไขของ UAT-04-004
