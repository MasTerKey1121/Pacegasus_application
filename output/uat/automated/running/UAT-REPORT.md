# ผลการทดสอบการวิ่งในลู่และ Park

ผลตามขั้นตอนที่นำเสนอ: **ผ่าน**

ทดสอบด้วย Flutter Integration Test บนแอปจริง บัญชีหลัก fortest.najajubjub@gmail.com รวมภาพจากรอบวิ่งในลู่และรอบ Park ให้เห็นขั้นตอนใช้งานต่อเนื่อง ภาพเหล่านี้มาจากคนละ session ไม่ใช่การเปลี่ยนสภาพแวดล้อมระหว่างวิ่งครั้งเดียว

| ลำดับ | กรณีทดสอบ | ผลที่ตรวจจริง | ผล |
|---|---|---|---|
| 1 | เปิดหน้าวิ่งในลู่ | เลือกสภาพแวดล้อมเป็นลู่ก่อนเริ่ม | ผ่าน |
| 2 | ระหว่างวิ่งในลู่และพัก | session เริ่มจริง พักแล้วเวลาไม่เพิ่มในช่วงตรวจ 3 วินาที และทำต่อได้ | ผ่าน |
| 3 | จบวิ่งในลู่ | สรุปแสดงระยะกรอกทดสอบ 0.10 km และส่ง feedback ได้เมื่อกรอกครบ | ผ่าน |
| 4 | เปิดหน้าวิ่ง Park | เลือก Park และโหลดรายการก่อนเริ่ม | ผ่าน |
| 5 | ระหว่างวิ่ง Park | ได้ตำแหน่ง GPS จริงและรออย่างน้อย 5 วินาทีก่อนจบ | ผ่าน |
| 6 | จบวิ่ง Park | แสดงสรุป session และบันทึก feedback ได้ ระยะ 0.00 km ขณะเครื่องอยู่กับที่ | ผ่าน |
| 7 | หน้ารับรางวัลหลังจบ Park | หน้าจอแสดง 5 เหรียญ ตรงกับยอดที่เพิ่มจริง | ผ่าน |
| 8 | ดูสถิติและประวัติ | มี session ใหม่หนึ่งรายการ ยอดสถิติตรงกับประวัติจริง | ผ่าน |
| 9 | เปิดรายละเอียดประวัติหลังโหลดข้อมูล | เปิดรายละเอียด session Park ที่บันทึกไว้และรอโหลดข้อมูลจริงสำเร็จ | ผ่าน |
