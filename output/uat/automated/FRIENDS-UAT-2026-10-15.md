## ผลฝั่งผู้ส่ง

[รายงาน 20:22:34](friend/UAT-REPORT-send.md)

- UID ผิดรูปแบบถูกปฏิเสธ
- เพิ่ม UID ของตนเองไม่ได้
- UID ของบัญชีรองแบบตัวพิมพ์เล็กใช้ส่งคำขอได้
- สถานะเป็น pending และปรากฏในแท็บส่งแล้ว
- ส่งซ้ำถูกปฏิเสธ มีคำขอค้างเพียงรายการเดียว
- ยกเลิกคำขอแล้วความสัมพันธ์กลับเป็น none และรายการหายจากหน้าจอ
- ส่งใหม่หลังยกเลิกได้ เก็บ friendship ID ของคำขอใหม่เพื่อเทียบฝั่งผู้รับ

## ผลฝั่งผู้รับ

[รายงาน 20:24:34](friend/UAT-REPORT-accept.md)

- สลับบัญชีผ่านเมนูแอปตามความจำเป็นของกรณีทดสอบ ยืนยันด้วย OTP ของผู้ใช้
- บัญชีรองเห็นคำขอจากบัญชีหลักเพียงหนึ่งรายการ friendship ID ตรงกับฝั่งผู้ส่ง
- กดตอบรับได้ ความสัมพันธ์เปลี่ยนเป็น accepted
- แท็บเพื่อนของฉันแสดงบัญชีหลักหนึ่งรายการ ทั้ง API และ UI ตรงกัน
