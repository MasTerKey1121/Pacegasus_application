## ผลที่ตรวจแล้ว

- ใช้ session เดิมได้ ไม่มีการขอ OTP หรือออกจากระบบในรอบนี้
- เริ่ม session จริงในระบบ สถานะ in_progress และ environment=treadmill
- กดพักแล้วเวลาไม่เพิ่มตลอดช่วงตรวจ 3 วินาที กดทำต่อแล้วเวลาเพิ่มต่อ
- เปิดหน้าจบแล้วกดวิ่งต่อได้ จากนั้นจบด้วยระยะทางทดสอบ 0.10 km ได้
- หน้าสรุปแสดงระยะทางตรง และยังส่งข้อมูลไม่ได้ก่อนกรอก feedback ครบ
- กรอก RPE/ความเครียด อารมณ์ good และไม่มีอาการบาดเจ็บ แล้วบันทึกสำเร็จ
- ตรวจ API หลังบันทึก มีการวิ่งสำเร็จเพิ่มหนึ่งรายการ ระยะ/เวลาเป็นบวก และ feedback ผูกกับ session เดิมถูกต้อง

## UAT-BUG-RUN-001 — รางวัลที่แสดงไม่ตรงยอดจริง

ความสำคัญเสนอ: P1 (ข้อมูลเหรียญไม่ตรงกัน)

ขั้นตอน: จบวิ่ง → ส่ง feedback → เปิดหน้ารางวัล → เปรียบเทียบยอดเหรียญฝั่งเซิร์ฟเวอร์ก่อนและหลัง

ผลจริง: หน้ารางวัลระบุ **20 เหรียญ** แต่ API ยอดเหรียญเพิ่ม **5 เหรียญ** ไม่มีการทำกิจกรรมรับ/ใช้เหรียญอื่นระหว่างตรวจ

คาดหวัง: ตัวเลขบนหน้ารางวัลและยอดที่เพิ่มจริงต้องตรงกันตามกฎรางวัลที่ทีมรับรอง

หลักฐาน: [ภาพรางวัล](screenshots/run-reward-mismatch.png), [ผล assertions](results.json)

จุดอ้างอิงเพื่อให้ผู้พัฒนาตรวจ: หน้า RunSummary สร้าง RewardScreen ด้วยค่าคงที่ coin=20, exp=50 ขณะที่ rpeService.award ให้ coins=5, exp=5 ความไม่ตรงของ EXP เป็นข้อพบจากการอ่านโค้ด ยังไม่ได้วัด delta EXP เป็น assertion ในรอบนี้

## ข้อมูลทดสอบที่ขาด

Side Quest สำหรับ treadmill/easy: API ตอบไม่พบรายการ จึงบันทึก checkpoint เป็น **blocked** และตรวจเส้นทางวิ่งหลักต่อโดยไม่มี Side Quest ไม่ให้รางวัล Side Quest เอง

## ข้อจำกัดของรอบ

ตัวรันทดสอบหยุดที่การเลื่อนไปหารายการประวัติซึ่งยังไม่ถูกสร้าง widget เพราะอยู่ล่างจอ เป็นปัญหาสคริปต์ ไม่ใช่หลักฐานว่าประวัติหาย แก้เป็น scrollUntilVisible และดำเนินการตรวจรายการเดิมต่อในรอบ run-review โดยไม่สร้าง session หรือ feedback ซ้ำ

กรณี GPS กลางแจ้ง ความแม่นยำเส้นทาง การฝึกครบเป้า Main Quest และทุกกรณีผิดปกติยังไม่รับรองจากรอบนี้
