# Pacegasus — แผนการทดสอบ UAT

วันที่จัดทำ: 15 ตุลาคม 2026

แผนนี้ระบุเฉพาะ **รหัส · กรณีทดสอบ · ผลที่คาดหวัง** รวม 88 กรณี แบ่งเป็น 7 กลุ่ม ไม่มีผลการทดสอบจริงปะปน

กลุ่ม 01–03 ทดสอบต่อเนื่องตามเส้นทางใช้งาน ส่วนโปรไฟล์ เพื่อน คลับ และร้านค้า/Avatar แยกทดสอบเป็นกลุ่มได้ ใช้บัญชีหลักเป็นผู้ส่งเพื่อนและสร้างคลับ บัญชีรองเป็นผู้รับเพื่อนและขอเข้าคลับ

ใช้ session เดิม ไม่ออกจากระบบโดยไม่จำเป็น หน้า Home รอโมเดลอย่างน้อย 3 วินาทีก่อนเก็บภาพ กรณีที่มีหลายค่า เช่น OTP ผิด/ไม่ครบ หรือยอดเหรียญพอดี/ไม่พอ ให้ทำแต่ละค่าแยกกัน ไม่ถือว่าทำครบจากค่าเดียว

C คือยอดเหรียญก่อนรายการ P คือราคาสินค้าที่แสดงก่อนกดซื้อ W และ R คือรางวัล Wellness และภารกิจที่ทีมกำหนดไว้ก่อนเริ่มทดสอบ ใช้ราคาปัจจุบันของรอบทดสอบ ไม่ตรึงราคาเสื้อจากรอบที่ผ่านมา

## แผนการทดสอบสมัครสมาชิกและ Onboarding

| รหัส | กรณีทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| UAT-01-001 | สมัครด้วยอีเมลสำเร็จ | ยืนยันสำเร็จ ไปเริ่ม Onboarding และอีเมลผูกกับบัญชีที่สมัคร |
| UAT-01-002 | ยังไม่ยอมรับนโยบาย | ดำเนินการสมัครไม่ได้ มีคำแนะนำ และไม่มีสถานะยอมรับนโยบายถูกบันทึกแทนผู้ใช้ |
| UAT-01-003 | อีเมลไม่ถูกต้อง | แจ้งให้แก้ไขอีเมล ไม่ไปขั้นตอนยืนยันว่าได้ส่งรหัสสำเร็จ |
| UAT-01-004 | OTP ผิดและไม่ครบ | รหัสไม่ครบ/ผิดไม่ผ่าน รหัสที่ถูกต้องผ่านได้ถ้าคำขอยังใช้ได้ ข้อความไม่ทำให้เข้าใจว่าเข้าสำเร็จ |
| UAT-01-005 | OTP หมดอายุ | ไม่เข้าสู่ระบบ แจ้งว่ารหัสใช้ไม่ได้ และมีทางขอรหัสใหม่ |
| UAT-01-006 | ส่ง OTP ใหม่และจำกัดการส่ง | ช่วงรอป้องกันการส่งถี่ หลังครบส่งใหม่ได้ และยืนยันรอบล่าสุดสำเร็จ |
| UAT-01-007 | ป้องกันใช้ OTP ซ้ำ | รหัสที่ใช้ไปแล้วไม่สร้าง session ใหม่ ต้องยืนยันตัวตนด้วยคำขอใหม่ |
| UAT-01-008 | สมัคร/เข้าสู่ระบบด้วย Google | ผู้ใช้ใหม่ผ่านขั้นตอนนโยบายตามที่รับรองแล้วไป Onboarding; ผู้ใช้เดิมได้บัญชีเดิมและไปหน้าตามสถานะ ไม่มีบัญชีซ้ำ |
| UAT-01-009 | ยกเลิก Google | กลับหน้าลงชื่อเข้าใช้ ไม่มี session และไม่ถือว่ายอมรับนโยบายแล้ว |
| UAT-01-010 | กรอกข้อมูลพื้นฐานถูกต้อง เว้นช่องบังคับ และกรอกค่าที่ขอบเขต/นอกขอบเขต | ข้อมูลถูกต้องบันทึกได้ ช่องบังคับและค่าที่ผิดมีคำแนะนำ ไม่รับวันเกิดอนาคตหรือวันที่ไม่มีจริง อายุ น้ำหนัก ส่วนสูง และวันวิ่งอยู่ในช่วงที่ระบบกำหนด หน่วยชัดเจน |
| UAT-01-011 | ประวัติบาดเจ็บและโรคประจำตัว | ไปต่อได้ตามข้อมูลบังคับ เก็บคำตอบตรงกับที่เลือก และเมื่อเปลี่ยนเป็นไม่มีไม่เหลือข้อมูลขัดแย้ง |
| UAT-01-012 | เป้าหมายและประวัติวิ่ง | ต้องมีเป้าหมายอย่างน้อยหนึ่งข้อ เป้าหมายเพิ่มความอึดไม่สร้างเป้าระยะทางเอง เมื่อกรอกครบเข้าสู่หน้าหลักได้ |
| UAT-01-013 | บันทึกและกลับมาทำ Onboarding ต่อ | ขั้นที่บันทึกแล้วไม่สูญหาย กลับเข้าสู่ขั้นตอนที่เหมาะสม เมื่อจบแล้วเข้าใหม่ไม่ถูกเริ่ม Onboarding ใหม่ |
| UAT-01-014 | บันทึก Onboarding ตอนเน็ตขัดข้อง | ไม่ข้ามขั้นโดยอ้างว่าสำเร็จทั้งที่ยังไม่บันทึก ข้อมูลไม่ซ้ำ และทำต่อได้เมื่อเชื่อมต่อกลับมา |

## แผนการทดสอบ Daily Wellness โปรแกรมและตารางฝึกซ้อม

| รหัส | กรณีทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| UAT-02-001 | Wellness ครั้งแรกของวัน | บันทึกค่าตรง วันนี้เป็นทำแล้ว ยอดเหรียญเท่ากับ C+W และงานเช็กอินบนหน้าหลักปรับตามสถานะ |
| UAT-02-002 | Wellness ไม่ครบ | แจ้งให้กรอกครบ ไม่ถือว่าเช็กอินแล้ว และไม่ได้รับรางวัล |
| UAT-02-003 | Wellness ค่าปลายสเกล | รับเฉพาะช่วง 1–5 ค่าที่เก็บตรง และคะแนนรวมตรงสูตรที่ทีมรับรอง |
| UAT-02-004 | แก้ไข Wellness ไม่รับรางวัลซ้ำ | เห็นค่าล่าสุด ยังมีรายการวันนี้รายการเดียว และยอดไม่เพิ่มจากการแก้ไข |
| UAT-02-005 | กดบันทึก Wellness ซ้ำ/ตอบกลับหาย | มีเช็กอินหนึ่งรายการและรางวัลหนึ่งครั้ง สถานะสุดท้ายตรงกันระหว่างหน้าเช็กอินกับหน้าหลัก |
| UAT-02-006 | เปิด Wellness ใหม่และกลับเข้าแอปด้วยบัญชีเดิมในวันเดียวกัน | แสดงว่าทำเช็กอินแล้วและคืนค่าที่บันทึกไว้ ไม่ให้รางวัลครั้งแรกซ้ำ หากต้องตรวจหลังเข้าสู่ระบบใหม่ให้แยกเป็นรอบที่จำเป็นต้องสลับ session |
| UAT-02-007 | เปลี่ยนวันและโหลดสถานะไม่สำเร็จ | วันใหม่ทำเช็กอินใหม่ได้ตามวันไทย; เมื่ออ่านสถานะล้มเหลวไม่สรุปเองว่ายังไม่ทำ และลองโหลดใหม่ได้ |
| UAT-02-008 | สมัครโปรแกรมครั้งแรก | มีโปรแกรม active หนึ่งรายการ ระดับและรายละเอียดตรงที่เลือก ไปจัดตารางและเห็นสถานะโปรแกรมได้ |
| UAT-02-009 | มีโปรแกรมอยู่แล้ว/กดสมัครซ้ำ | กลับไปใช้โปรแกรมปัจจุบันได้ ไม่มีโปรแกรม active ซ้ำ และไม่ยกเลิกโปรแกรมเดิมโดยไม่ยืนยัน |
| UAT-02-010 | จัดตาราง Easy 3 วัน และ Long 1 วัน แล้วบันทึกและเปิดตรวจใหม่ | มี Easy 3 วันและ Long 1 วันรวม 4 วัน วันที่ตรงที่เลือก วันอื่นไม่ถูกเพิ่มกิจกรรมเอง บันทึกได้เมื่อครบ กลับ Home และปิดเปิดแอปแล้วยังได้ตารางเดิม ไม่มีเควสซ้ำ |
| UAT-02-011 | วางกิจกรรมไม่ครบ วาง Easy เกินโควตา และวางกิจกรรมหนักติดกันในสัปดาห์ที่รองรับ | ตารางไม่ครบกดบันทึกไม่ได้ Easy ไม่เกิน 3 วันสำหรับแผนนี้ กิจกรรมหนักถูกตรวจตามกฎของโปรแกรม เมื่อแก้ให้ถูกต้องจึงบันทึกได้ |
| UAT-02-012 | เปลี่ยนสัปดาห์/เฟสและวันล็อก | แต่ละสัปดาห์แสดงข้อกำหนดของตัวเอง วันล็อกแก้ไม่ได้ ตารางเดิมไม่ถูกล้าง; Beginner ไม่ถูกเพิ่ม Race/เฟสที่ไม่มีในโปรแกรม |
| UAT-02-013 | บันทึกตารางสำเร็จแต่อ่านกลับไม่สำเร็จ | ไม่บันทึกซ้ำเพียงเพราะโหลดกลับล้มเหลว เมื่ออ่านสำเร็จได้ตารางที่บันทึกจริงหนึ่งชุด |
| UAT-02-014 | ยกเลิกโปรแกรมและเริ่มใหม่ | กดกลับไม่เปลี่ยนข้อมูล ยืนยันแล้วโปรแกรมเดิมไม่ active ประวัติเดิมยังอยู่ สมัครใหม่ได้และไม่นำตารางเก่ามาทับโปรแกรมใหม่ |

## แผนการทดสอบบันทึกวิ่ง สรุปผล ประวัติ สถิติ และอันดับ

| รหัส | กรณีทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| UAT-03-001 | เริ่มวิ่งจากแผนวันนี้ | ประเภทวิ่งตรงแผน สภาพแวดล้อมตรงที่เลือก เริ่ม session เดียวและเข้าสู่หน้าวิ่ง |
| UAT-03-002 | เลือกสภาพแวดล้อมแต่ละแบบและตรวจรายการ Side Quest ก่อนเริ่ม | รายการตรงกับสภาพแวดล้อมและประเภทฝึก ไม่มีรายการจากตัวเลือกก่อนหน้าปะปน หากไม่มีเควสให้แสดงสถานะตามกติกาที่กำหนด ไม่แสดงว่าโหลดสำเร็จทั้งที่เกิดข้อผิดพลาด |
| UAT-03-003 | เริ่มตอนโหลด/โหลดเควสล้มเหลว/กดซ้ำ | ไม่เริ่มระหว่างยังโหลด มีทางแก้เมื่อโหลดล้มเหลว และหลังเริ่มสำเร็จมี session และการผูกเควสเพียงชุดเดียว |
| UAT-03-004 | เลือก Park รออย่างน้อย 5 วินาทีและให้ GPS พร้อม แล้วจบวิ่ง; แยกรอบเดิน/วิ่งตามเส้นทางอ้างอิง | รับตำแหน่งจริงก่อนจบ บันทึกเวลา จุด GPS และแผนที่ได้ อยู่กับที่ระยะเป็นศูนย์ได้ รอบเคลื่อนที่ต้องได้เส้นทางและระยะในความคลาดเคลื่อนที่ทีมกำหนด ไม่ใช้ผลอยู่กับที่แทนการตรวจความแม่นยำ |
| UAT-03-005 | ปฏิเสธ GPS/ปิดบริการตำแหน่ง | แจ้งสาเหตุและวิธีแก้ ไม่แสดงเส้นทางหรือระยะ GPS ที่ไม่ได้บันทึกจริง หลังแก้กลับไปเริ่มหรือทำต่อได้ตามพฤติกรรมที่รับรอง |
| UAT-03-006 | แผนที่โหลดไม่ได้ | แจ้งปัญหาแผนที่ เวลา/ระยะและ GPS ยังบันทึกได้ตามสิทธิ์ และไม่ติดหน้ารอไม่สิ้นสุด |
| UAT-03-007 | พักและวิ่งต่อ | ช่วงพักไม่เพิ่มเวลาออกกำลังและระยะที่นับ เมื่อทำต่อค่าต่อจากเดิมตามกติกาที่รับรอง |
| UAT-03-008 | สลับแอปและล็อกหน้าจอ | เวลา ระยะ และเส้นทางเป็นไปตามนโยบายการทำงานเบื้องหลังที่รับรอง ไม่มี session ซ้ำหรือข้อมูลหายโดยไม่แจ้ง |
| UAT-03-009 | กู้ session หลังปิดแอป | กู้ session เดิมพร้อมค่าที่บันทึกไว้และสถานะเควส การสูญเสียระหว่างจุดบันทึกไม่เกินเกณฑ์ที่รับรอง ไม่มีรายการวิ่งใหม่ซ้ำ |
| UAT-03-010 | เลือกวิ่งในลู่ เริ่มวิ่ง กรอกระยะจากลู่ แล้วจบและเปิดสรุป | บันทึกสภาพแวดล้อมเป็นลู่ ระยะตรงค่าที่กรอก เวลาและเพซสัมพันธ์กัน ไม่มีเส้นทาง GPS ที่สร้างขึ้นเอง หากใช้ระยะทดสอบ 0.10 km ต้องแสดง 0.10 km ตรงกัน |
| UAT-03-011 | ยืนยันจบและกดจบซ้ำ | ยกเลิก dialog ไม่ทำให้ session จบ ยืนยันแล้วจบเพียงครั้งเดียว ได้ประวัติรายการเดียว |
| UAT-03-012 | จบตอนเน็ตขัดข้อง | ไม่แสดงสำเร็จผิดสถานะ ทำให้เสร็จได้โดยข้อมูลไม่ซ้ำ เวลา/ระยะไม่ถูกล้างก่อนบันทึกยืนยันสำเร็จ |
| UAT-03-013 | Side Quest สำเร็จและรางวัลไม่ซ้ำ | เควสสำเร็จหนึ่งครั้ง รางวัลรวมเพิ่ม R เพียงครั้งเดียว และสถานะยังตรงหลังเปิดใหม่ |
| UAT-03-014 | เควสที่ยังไม่ทำไม่สำเร็จเอง | เฉพาะรายการที่ทำสำเร็จได้รางวัล การจบวิ่งไม่ทำให้รายการที่เหลือสำเร็จอัตโนมัติ |
| UAT-03-015 | วิ่งให้ครบ Main Quest ตรวจรางวัล เหรียญ EXP และการเพิ่มเลเวล แยกรอบ Park กับลู่ | สถานะภารกิจเปลี่ยนเมื่อครบเงื่อนไข รางวัลบนหน้าจอตรงยอดที่เพิ่มจริงทั้งเหรียญและ EXP เลเวล/EXP คงเหลือตรงสูตร เปิดใหม่ไม่รับซ้ำ |
| UAT-03-016 | สรุปตัวเลขและ RPE | สรุปตรง session เพซถูกต้อง feedback ผูกกับ session เดิม และข้อมูลปลายสเกลเก็บถูกต้อง |
| UAT-03-017 | ส่ง feedback ซ้ำ/เน็ตขัดข้อง | ไม่สร้าง feedback หรือรางวัลซ้ำ ข้อผิดพลาดไม่แสดงเป็นสำเร็จ และบันทึกต่อได้โดยข้อมูลเดิมไม่สูญหาย |
| UAT-03-018 | ตรวจประวัติและสถิติจากการวิ่งสำเร็จ 2 km/600 วินาที และ 3 km/1,200 วินาทีในช่วงเดียวกัน โดยไม่มีการวิ่งสำเร็จอื่น | แสดง 2 รายการสำเร็จ รวม 5 km, 1,800 วินาที และเพซรวม 6:00 min/km; รายการยกเลิก/ยังไม่จบไม่รวมในยอด |
| UAT-03-019 | ไม่มีประวัติ/เปลี่ยนช่วง/ค่าที่วัดไม่ได้ | ไม่มีข้อมูลแสดงสถานะว่างตามจริง ช่วงวันที่ไทยถูกต้อง ค่าไม่ทราบไม่ถูกแทนเป็นค่าที่วัดจริง และไม่เกิดหารด้วยศูนย์ |
| UAT-03-020 | อันดับบุคคลหลังจบวิ่ง | นับเฉพาะวิ่งสำเร็จระยะมากกว่า 0 ของสัปดาห์ไทย เรียงระยะจากมากไปน้อย แสดงไม่เกิน 50 อันดับ; ผู้ใช้นอก Top 50 ไม่ถูกแสดงเป็นอันดับใน Top 50 |
